# salahuddin-portfolio

Personal portfolio of Salahuddin Umer, SEO & Organic Growth Specialist.
Live: https://salahuddinumer08.github.io/salahuddin-portfolio/

Plain static HTML and CSS served by GitHub Pages from the `main` branch root. There's no build step.

- `index.html`: home page
- `work/*.html`: case studies
- `assets/css/site.css`, `assets/js/site.js`: styles and small enhancements (the site works without JS)
- `assets/Salahuddin-Umer-SEO-Resume.pdf`: resume download
- `sitemap.xml`: submit in Google Search Console (URL-prefix property)

Anything wrapped in `<mark class="tbc">` still needs confirming and must be resolved before publishing.
